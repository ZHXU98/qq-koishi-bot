生成 A股「盘后复盘」报告并推送到 QQ。

1. 先判断今天是否为 A 股交易日；休市则**不要推送**，直接结束并说明「今日休市」。
2. 工作目录 = 本项目根（`qq-koishi-bot`）。技能文档**以项目内为准**：读 `skills/a-share-daily-review/SKILL.md`，按默认路径（技术面三维分析）执行；风格基准读 `skills/a-share-daily-review/references/house_style.md`，成品手法可翻 `skills/a-share-daily-review/examples/`（只看手法，不抄结构）。`~/.workbuddy/skills/` 下的是副本，冲突时以项目内为准。取数前先 `export PATH="$HOME/.local/bin:$PATH"`（westock CLI 不在默认 PATH）。所有路径相对项目根。
3. 视角是**收盘全维复盘**：六大指数收盘与成交额、涨跌分布、板块与题材强弱、资金流向、市场状态定位，末尾给「次日开盘关注清单」。只写取到的数据，不编造。
4. **情绪分析**（四行，简约）：
   ```
   westock changedist
   westock market-overview --type trade
   ```
   - 情绪：冰点 / 低迷 / 中性 / 修复 / 活跃 / 亢奋（六档选一）+ 涨 x / 跌 y，涨停 a / 跌停 b，成交额 d 亿（标注放量或缩量多少）
   - 连板梯队：最高几板、几进几（能从涨停梯队数据顺手拿到才写，拿不到就整行省略；westock 无连板天梯命令，不要调用 westock-tool）
   - 赚钱效应：一句话（昨日涨停今日溢价、高位股是否补跌）
   - 周期定位：低位震荡 / 主升 / 高位震荡 / 主跌（四选一）
   不写方法论、不解释指标定义。
5. 写 HTML（**版式自己设计，不要套模板**）：
   - 必讲要素：一句话定性 → 量能与涨跌分布 → 指数全表 → 情绪与周期定位 → 技术面（均线与关键位）→ 板块与资金 → 次日关注清单 → 风险提示
   - **篇幅**：这份是四份里唯一允许长的——3-5 屏、6～9 个编号章节，表格为主、图表为辅。
     每节用「结论式标题 + 主表 + 图 + 一句 40～80 字解读」，表里可加状态列（主升 / 脉冲 / 轮动 / 退潮 四档标签）。
     超过 9 节就合并，宁可 7 节讲透，不要 12 节各说一句。
     密度与组织可参照 `skills/a-share-daily-review/examples/2026-11-19-复盘-表格版参照.jpg`（只看手法，不抄结构与颜色值）

   - **禁止复用历史 HTML 的骨架或 class 结构**，每期可以不同；章节顺序、分栏、图表组合随你按当期内容安排
   - 只守三条硬约束：浅底深字（深色只做小黑标签/粗黑细线，不做整页暗色，也不要整块深色刊头）、上涨红 `#c0392b` / 下跌绿 `#2d6a4f`、第一屏能读到结论

   - 情绪做成一个独立小块，别挤占技术面篇幅
   - 章节标题建议"编号 + 带数据的副标题"（如「01 量能与涨跌分布 · 成交 14222 亿，放大 1171 亿」）
