# 成品样例（2026-11-20 四份）

同一个交易日、同一套数据源，四个时点的四份报告，用来看「风格一致但版式不同」到底长什么样。

| 文件 | 时段 | 版式手法 |
|---|---|---|
| `A股-2026-11-20-早盘.html` | 盘前 08:10 | 中文编号（一～五）+ 逐条对照表，像战前简报 |
| `A股-2026-11-20-开盘.html` | 开盘 09:30（竞价版） | 缺口阶梯（8 行横条）+ 三格竞价数字 + 外盘三栏 + 对账四项（兑现/部分/背离）+ 深色「盯一句」块，约 1.2 屏 |
| `A股-2026-11-20-午盘.html` | 午盘 11:40 | 风向三段（进/出/换）+ 强弱两端 + 双向资金条 + 风格切换 + 热度错位 + 情绪小块，约 3 屏 |
| `A股-2026-11-20-复盘.html` | 盘后 16:00 | 刊头 + 核心结论块 + `01/02/03` 编号章节，最完整 |
| `2026-11-19-复盘-表格版参照.jpg` | 盘后 16:00 | 表格型长报告：8～9 个编号章节，每节「结论式标题 + 主表 + 图 + 一句解读」，状态列用主升/脉冲/轮动/退潮四色标签 |

> 最后一张是用户认可并指定的盘后版式参照（原 HTML 已不在仓库，只留截图）。
> 它代表盘后可以走到的高密度上限——**早盘/开盘不要照这个量级铺开；午盘 2-3 屏为界**。
> 具体拆解见 `references/house_style.md` 的「盘后专属：可以把密度拉满」。

## 怎么看

- **学气质**：主标题怎么写、导语几句、图表下面那句口径注怎么落、红绿怎么用、密度到什么程度。
- **不要学结构**：这四份的 `<style>`、class 名、DOM 骨架都是当期的临时决定，不要复制。
  下一期如果长得跟这四份一样，说明没有按当期内容重新设计，属于跑偏。

## 打开方式

HTML 用的是相对路径引用 `../../../a-share-report/vendor/echarts.min.js`，
在仓库目录内直接浏览器打开即可看到图表；单独拷出去会因为找不到 echarts 而没有图。
