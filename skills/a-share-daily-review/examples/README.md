# 成品样例（2026-11-20 四份）

同一个交易日、同一套数据源，四个时点的四份报告，用来看「风格一致但版式不同」到底长什么样。

| 文件 | 时段 | 版式手法 |
|---|---|---|
| `A股-2026-11-20-早盘.html` | 盘前 08:10 | 中文编号（一～五）+ 逐条对照表，像战前简报 |
| `A股-2026-11-20-开盘.html` | 开盘 09:30 | 数字墙 + 反差表（昨收 → 今开 → 反转 pct），像行情牌 |
| `A股-2026-11-20-午盘.html` | 午盘 11:40 | 指标带 + 最短正文，情绪三行嵌在中部 |
| `A股-2026-11-20-复盘.html` | 盘后 16:00 | 刊头 + 核心结论块 + `01/02/03` 编号章节，最完整 |

## 怎么看

- **学气质**：主标题怎么写、导语几句、图表下面那句口径注怎么落、红绿怎么用、密度到什么程度。
- **不要学结构**：这四份的 `<style>`、class 名、DOM 骨架都是当期的临时决定，不要复制。
  下一期如果长得跟这四份一样，说明没有按当期内容重新设计，属于跑偏。

## 打开方式

HTML 用的是相对路径引用 `../../../a-share-report/vendor/echarts.min.js`，
在仓库目录内直接浏览器打开即可看到图表；单独拷出去会因为找不到 echarts 而没有图。
