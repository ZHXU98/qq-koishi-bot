# 本项目的报告风格（风格 DNA，不是模板）

这份文件描述「我们家的报告长什么样」，供模型**模仿**，不是拿去填空的骨架。

**用法**：读完这一页，把它当成一个编辑的审美偏好，而不是一份 HTML 规格书。
版式、章节顺序、卡片形态、图表选型每期都可以重新发明；只有"气质"要保持一致。
**禁止**把本文件里的任何元素当成必须出现的组件，也禁止照抄 `examples/` 里任何一份的 class 结构与 DOM 骨架。

---

## 一句话概括这种风格

一份给手机看的高密度卖方简报：**标题就是结论，数字就是论据，版式随内容变**。

---

## 六个共同气质（四条必须，两条建议）

### 1. 标题必须自带结论与数字（必须）

不做「今日市场回顾」这种空标题。主标题是一个判断句，里面要有具体数字或极具体的描写：

- `涨的只有 313 家，跌停 68 家：这是一次清算`
- `半日跌 1.57%，跌停 68 家说明不只是科技的事`
- `全线低开，科创50 一个人跌 3.21%`
- `外盘先跌为敬，A 股今天开盘只有一条路`

手法：前半句给事实（带数字），冒号/破折号后半句给判断；或者一句白描 + 一个反差数字。
标题长度 12～24 字，超过两行就砍。

### 2. 首屏就要把话说尽（必须）

第一屏（600px 宽下约 800px 高）读完，应该已经知道：今天怎么定性、关键数字是多少、为什么。
三段结构最常见，但不强制：

1. **刊头**：`A股盘后复盘 · 2026-11-20` 这种「产品名 · 时段 · 日期」的小字行，加一个时段标签（`收盘复盘` / `开盘快报` / `盘前简报` / `午盘`）
2. **大字标题**（第 1 条）
3. **导语 1～3 句**：把标题的逻辑说清，允许带 inline 高亮数字（红涨绿跌）

之后才是"核心结论"或指标带。**不要**用「目录」「摘要」「免责声明」占掉首屏。

### 3. 章节用编号 + 带数据的副标题（必须）

章节标题不是「板块表现」，而是「板块与资金 · 银行独涨 2.52%，主力净流入 262 亿」。
编号用 `01 / 02 / 03` 或 `一、二、三` 都行，一份报告内部统一即可。
副标题里的数字要来自正文，不能是装饰。

### 4. 图表必须配一句口径注（必须）

每张图下面一句小字，说明"这张图在讲什么、怎么算的、颜色什么意思"：

- `按涨跌幅区间统计个股家数。左侧为跌（绿），右侧为涨（红）；跌 5~7% 的 1728 只与跌超 7% 的 1064 只合计 2792 只，占全市场一半。`

这句话本身要有信息量，不是「数据来源：xx」。

### 5. 数字的排版优先级高于文字（建议）

- 关键数字用大字号（24～44px）+ 颜色 + 单位小字，别混在句子里
- 涨跌用 inline 色块/加粗，涨红 `#c0392b`～`#dc2626`，跌绿 `#2d6a4f`～`#16a34a`
- 表格列右对齐数字，涨跌幅整列染色，不要每格加边框
- 相邻数字组之间用细线或留白分隔，密度高但不糊

### 6. 结尾一句风险提示，一句就够（建议）

`以上分析基于公开数据，不构成投资建议。` 不要写三段免责。

## 视觉参数（可调，不是硬值）

| 项 | 参考值 | 说明 |
|---|---|---|
| 画布宽度 | 600 CSS px（推送图 2x） | 手机端阅读，设计按 600 宽做 |
| 时长 | 早盘/开盘/午盘 1～2 屏；复盘 3～5 屏 | 复盘允许长，但不许灌水 |
| 底色 | 米白 `#faf8f5` / 纯白 `#fff` | 深色只能做刊头或单个重点块，不能整页 |
| 正文色 | `#1a1a1a`～`#2b2b2b` | 灰阶做层次，不用彩色正文 |
| 点缀色 | 石板蓝 `#1e3a5f`～`#4a5b78` | 分隔线、编号、小标签 |
| 图表库 | ECharts 5（本地 `a-share-report/vendor/echarts.min.js`） | 离线渲染必须走相对路径 |
| 字体 | 系统中文栈（PingFang / Noto Sans SC） | 不引外链字体 |

## 四份报告为什么要长得不一样

同一套气质，不同时段重点不同，版式自然分叉。这不是"风格不统一"，是"内容决定形式"：

| 时段 | 版式倾向 | 为什么 |
|---|---|---|
| 早盘 08:10 | 编号清单 + 对照表，像一份战前简报 | 内容本质是「假设 → 检验」，需要逐条对 |
| 开盘 09:30 | 数字墙 + 反差表，像一块行情牌 | 内容本质是「定价程度」，靠数字对比说话 |
| 午盘 11:40 | 指标带 + 单句判断，最短 | 半天数据少，说多了就是凑 |
| 盘后 16:00 | 刊头 + 核心结论块 + 6～9 个编号章节，表格为主图表为辅 | 维度最多（量能/板块/涨停梯队/资金/技术/情绪/次日），压进 1-2 屏必然丢信息 |

每期都可以换手法：这一期用双列强弱，下一期用条形对比，再下一期用时间轴——只要气质在。

## 盘后专属：可以把密度拉满（也只有盘后可以）

盘后是四份里唯一允许"长"的。上面写的「1-2 屏」只约束早盘、开盘、午盘；复盘可以 3-5 屏、6～9 个编号章节。
但密度高不等于堆砌，这份长报告有一条成熟的骨架逻辑可以用（用不用随当期内容）：

**每节 = 结论式标题 → 主表 → 图 → 一句解读**

| 元素 | 做法 | 例子 |
|---|---|---|
| 章节标题 | 编号 + 结论 + 数字，不用名词 | `四、涨停梯队：30 只涨停、8 只压在 PCB 一条线上` |
| 主表 | 先给结论，列里带口径 | `状态 / 方向 / 涨幅 / 涨停数 / 逻辑与证据` |
| 状态列 | 4 档定性标签替掉长句形容 | `主升` `脉冲` `轮动` `退潮`，四色区分 |
| 图 | 只在"形态比数字更直观"时上：横条排行、区间分布、走势折线 | 板块涨跌幅横条（负绿正红）、涨跌幅分布柱 |
| 表下解读 | 40～80 字，讲"为什么是这样"，不是重复表格 | `利率平头宽断，不是切换，是新通道…` |
| 图下口径注 | 一句话讲清统计范围与颜色 | `行业涨跌幅按 8 只权重股…绿跌红涨` |

可选章节（按当日有没有内容决定要不要，不必全上）：大盘概览 / 量能与涨跌分布 / 板块与题材 / 涨停梯队 / 连板与个股 / 资金流向 / 技术面 / 情绪与周期 / 次日推演。

**边界**：
- 超过 9 节就合并，宁可 7 节讲透，不要 12 节各讲一句
- 早盘 / 开盘 / 午盘**不要**照这个量级铺开，那三份的价值在"短而准"
- 表格化不等于 Excel：一屏最多两张表，表与表之间必须有解读文字，否则读起来像对账单

---

## 反面清单（写了就是跑偏）

- 标题写成「A股市场每日复盘报告」这种公文题
- 首屏放免责声明、目录、数据来源说明
- 章节标题只有名词没有结论
- 图表没有口径注，或者注释是「数据来源：某平台」
- 整页深色背景 + 霓虹色，做成数据大屏
- 红绿用反（涨绿跌红）
- 为了凑图表画图：三个数据的对比也硬上一张图
- 六份报告长得一模一样，只是换了数字
