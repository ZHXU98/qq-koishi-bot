# 多周期技术分析使用指南

> `/an` 命令：基于日线 / 周线 / 月线 K 线，结合 MA、BOLL、MACD、量价、箱体与前高前低，输出一份“方向 + 阶段 + 关键位 + 操作参考”的综合分析。  
> 它不是日内点位计算器，而是告诉你：**大方向在哪、当前处于什么阶段、关键压力支撑在哪、适合追还是等回踩**。

---

## 命令格式

```
/an <代码或名称>
/分析 <代码或名称>
/技术分析 <代码或名称>
```

例：

```
/an 600519
/an 兆易创新
/an 563020
/an 红利低波
```

---

## `/an` 和 `/t` 的区别

| 命令 | 解决的问题 | 数据周期 | 输出重点 |
|------|------------|----------|----------|
| `/an` | 这只票现在能不能看、处于什么阶段、关键价位在哪里 | 日线 / 周线 / 月线 | 趋势方向、结构阶段、支撑压力、持仓/空仓建议 |
| `/t` | 今天盘中怎么做T，哪里卖、哪里买回 | 实时分时 + 日线结构 | 日内 T 位、分时黄线、开盘轨迹、量能确认 |

简单说：

```
先用 /an 判断“大方向和值不值得做”
再用 /t 判断“今天盘中具体怎么做”
```

---

## 核心框架：月线定方向，周线定阶段，日线定操作

`/an` 不只看一张日线图，而是三层判断：

| 周期 | 作用 | 主要回答 |
|------|------|----------|
| 月线 | 长期结构 | 大趋势是否还在？是不是长期弱势？ |
| 周线 | 中期阶段 | 是主升、震荡、反弹，还是下跌中继？ |
| 日线 | 短线节奏 | 现在该追、等回踩，还是反弹减仓？ |

综合评分权重：

```
日线 30% + 周线 40% + 月线 30%
```

为什么周线权重最高？

- 日线太敏感，容易被一两天涨跌干扰。
- 月线太慢，适合看大背景，但不适合决定短线操作。
- 周线最适合判断一只票处于“主升 / 震荡 / 下跌修复”的中期阶段。

文字报告大致结构：

```

━━━ 综合结论 ━━━

...

━━━ 周线：中期阶段 ━━━
...

━━━ 日线：短线节奏 ━━━
...

...

━━━ 操作参考 ━━━

### 综合评级

| 评级 | 含义 | 常见处理 |
|------|------|----------|
| 偏强 | 多周期共振偏多 | 趋势持有，等回踩低吸 |
| 中性偏强 | 结构有修复，但还不够强 | 回踩确认，不追高 |
| 震荡 | 多周期分歧，没有单边方向 | 高抛低吸，等突破或跌破 |
| 中性偏弱 | 有压制，反弹可信度有限 | 反弹观察，压力减仓 |
| 偏弱 | 多周期偏空 | 风险规避，反弹减仓 |

## 趋势判断：MA5 / MA10 / MA20 / MA60

`/an` 主要用 5、10、20、60 均线判断趋势结构。

| 结构 | 判断条件 | 含义 |
|------|----------|------|
| 上升趋势 | 收盘价 > MA5 > MA10 > MA20，且 MA20 走平或上行 | 短中期多头排列 |
| 下降趋势 | 收盘价 < MA5 < MA10 < MA20，且 MA20 走平或下行 | 短中期空头排列 |
| 中性偏强 | 收盘价在 MA20 上方，但均线未完全多头 | 有修复，但未完全走强 |
| 中性偏弱 | 收盘价在 MA20 下方，但均线未完全空头 | 有压力，但未完全走坏 |
| 震荡 | 以上条件都不明显 | 多空分歧，方向不清 |

均线不是预测工具，而是“位置工具”：

- 价格在 MA20 上方：中期成本线之上，偏强。
- 价格在 MA20 下方：中期成本线之下，偏弱。
- MA60 通常代表更慢的趋势成本，常作为中期支撑/压力参考。

## BOLL：判断价格在通道里的位置

BOLL 使用 20 周期布林带：

```
中轨 = MA20
上轨 = MA20 + 2 × 标准差
下轨 = MA20 - 2 × 标准差
```

报告里会给出：

```
MA20 391.79 / BOLL 337.10 ~ 455.81
```

含义：

| 位置 | 含义 | 处理 |
|------|------|------|
| 靠近 BOLL 上轨 | 短线偏贵，容易遇到压力 | 不追高，看能否放量突破 |
| BOLL 中部 | 中性位置 | 等方向选择 |
| 靠近 BOLL 下轨 | 短线偏便宜，但也可能弱势 | 看是否缩量企稳或底背离 |
| 放量突破上轨 | 强势扩张 | 回踩不破再确认 |
| 放量跌破下轨 | 弱势扩张 | 优先控风险 |

> 注意：强趋势里价格可以长期贴上轨或下轨运行，所以 BOLL 不能单独当买卖点，只能配合量价和趋势。

## MACD：判断动能与背离

MACD 使用常规参数：

```
EMA12 / EMA26 / DEA9
DIF = EMA12 - EMA26
DEA = DIF 的 9 周期 EMA
柱 = (DIF - DEA) × 2
```

报告中的 MACD 描述通常长这样：

```
偏多 / 红柱收敛，近现金叉，普通底背离
```

### 金叉 / 死叉

| 信号 | 含义 | 解释 |
|------|------|------|
| 金叉 | DIF 上穿 DEA | 动能转强，尤其在低位更有参考价值 |
| 死叉 | DIF 下穿 DEA | 动能转弱，尤其在高位更需要小心 |
| 红柱放大 | 多头动能增强 | 上涨更有持续性 |
| 红柱收敛 | 多头动能减弱 | 上涨开始变慢 |
| 绿柱放大 | 空头动能增强 | 下跌压力加大 |
| 绿柱收敛 | 空头动能减弱 | 下跌开始钝化 |

### 背离识别

第二版 `/an` 不再用简单的“相邻高低点”判断背离，而是：

```
最近 70 根 K 线里找摆动高点 / 摆动低点
价格创新高但 DIF 没创新高 → 顶背离
价格创新低但 DIF 没创新低 → 底背离
```

| 背离 | 条件 | 含义 |
|------|------|------|
| 顶背离 | 价格新高，DIF 走弱 | 上涨动能不足，冲高回落风险上升 |
| 底背离 | 价格新低，DIF 走强 | 下跌动能衰竭，可能出现修复 |
| 强背离 | 价格偏离幅度更大 | 信号更明显，但仍需量价确认 |

> 背离不是反转保证，只是“动能不同步”的警报。真正有效通常还要配合放量阳线、站回均线或突破前高。

## 箱体：判断当前在区间的哪个位置

第二版 `/an` 增加了箱体识别。

当前实现口径：

```
箱顶 = 最近 20 期前高
箱底 = 最近 20 期前低
箱体宽度 = (箱顶 - 箱底) / 箱底
```

> 日线就是最近 20 个交易日，周线就是最近 20 周，月线就是最近 20 个月。

箱体状态：

| 状态 | 判断 | 含义 |
|------|------|------|
| 靠近箱体上沿 | 当前价处于箱体上方 25% 区域 | 接近压力，不宜盲目追高 |
| 靠近箱体下沿 | 当前价处于箱体下方 25% 区域 | 接近支撑，看是否有承接 |
| 突破箱体上沿 | 收盘价 > 箱顶 × 1.005 | 可能走出区间，需要看量能确认 |
| 跌破箱体下沿 | 收盘价 < 箱底 × 0.995 | 区间破坏，优先控制风险 |
| 箱体震荡 | 仍在箱体中部 | 适合按区间看，不追涨杀跌 |

## 前高前低：判断突破和破位

报告里会出现：

```
20期前高455.81，20期前低363.00
```

含义：

- **前高**：最近 20 期中，不含当前 K 的最高价。
- **前低**：最近 20 期中，不含当前 K 的最低价。

为什么排除当前 K？

- 如果当前 K 自己就是最高点，直接拿它当“前高”会误判。
- 只有突破过去形成的高点，才叫真正突破前高。

## 量价信号：第二版新增的重点

`/an` 不只看价格涨跌，还看量是否配合。

当前量能口径：

```
量比 = 当前周期成交量 / 最近 5 期均量
```

量能分层：

| 量比 | 状态 |
|------|------|
| ≥ 1.5 | 放量 |
| 1.2 ~ 1.5 | 温和放量 |
| 0.8 ~ 1.2 | 正常量 |
| 0.5 ~ 0.8 | 缩量 |
| < 0.5 | 极缩量 |

### 量价结构信号

| 信号 | 判断 | 含义 | 操作参考 |
|------|------|------|----------|
| 放量突破前高 | 收盘突破 20 期前高 0.5% 以上，且量比 ≥ 1.2 | 有资金推动突破 | 不直接追高，等回踩不破确认 |
| 放量跌破前低 | 收盘跌破 20 期前低 0.5% 以上，且量比 ≥ 1.2 | 破位带量，风险加大 | 优先控风险 |
| 放量滞涨/上影压力 | 放量上涨但实体小，上影明显 | 上方抛压重 | 持仓可减，空仓不追 |
| 放量下探有承接 | 放量下跌但下影明显 | 有资金低位承接 | 观察是否转强 |
| 缩量回踩关键位 | 靠近 MA20 或箱底，缩量且跌幅不大 | 抛压不强 | 等放量转强后低吸 |
| 放量突破 BOLL 上轨 | 收盘上穿上轨且放量 | 强势扩张 | 回踩不破才更稳 |
| 放量跌破 BOLL 下轨 | 收盘跌破下轨且放量 | 弱势扩张 | 不急着接 |

## 综合评分怎么来

每个周期都会得到一个分数，再按日 / 周 / 月权重汇总。

### 周期内加减分

| 条件 | 分数方向 |
|------|----------|
| 上升趋势 | +2 |
| 下降趋势 | -2 |
| 现价在 MA20 上方 | +1 |
| 现价在 MA20 下方 | -1 |
| 最近金叉 | +0.5 |
| 最近死叉 | -0.5 |
| 底背离 | +0.5 |
| 顶背离 | -0.5 |
| 放量上涨 | +0.5 |
| 放量下跌 | -0.5 |
| 放量突破前高 | +1 |
| 放量跌破前低 | -1 |
| 放量滞涨 | -0.5 |
| 缩量回踩关键位 | +0.5 |
| 突破箱体上沿 | +0.4 |
| 跌破箱体下沿 | -0.4 |

### 总分映射

| 加权分 | 评级 | 操作风格 |
|--------|------|----------|
| ≥ 1.2 | 偏强 | 趋势持有 / 回踩低吸 |
| 0.4 ~ 1.2 | 中性偏强 | 回踩确认 / 不追高 |
| -0.4 ~ 0.4 | 震荡 | 高抛低吸 / 等方向 |
| -1.2 ~ -0.4 | 中性偏弱 | 反弹观察 / 压力减仓 |
| ≤ -1.2 | 偏弱 | 风险规避 / 反弹减仓 |

> 评分是为了统一口径，不代表胜率，也不代表仓位建议。

## 关键价位怎么来

报告会输出：

```
压力：391.79 / 425.65 / 455.81 / 467.02
支撑：337.10 / 305.48 / 296.25
失效位：跌破 337.10，当前短线判断转弱
```

候选来源：

| 类型 | 来源 |
|------|------|
| 压力 | 日线/周线 MA20、MA60、BOLL 上轨、最近高点、箱顶、20期前高 |
| 支撑 | 日线/周线 MA20、MA60、BOLL 下轨、最近低点、箱底、20期前低 |
| 失效位 | 优先取最近的日线支撑 |

筛选原则：

- 压力只保留当前价上方附近的关键位。
- 支撑只保留当前价下方附近的关键位。
- 同一价格四舍五入后去重。
- 最多展示 4 个，避免噪音太多。

## 操作建议怎么理解

报告会分三类：

### 已持仓

回答：**现在仓位怎么处理？**

常见逻辑：

- 偏弱：反弹到压力位附近缩量，考虑减仓。
- 偏强：趋势未破可以持有，回踩关键支撑不破可继续观察。
- 放量跌破前低：优先减风险。
- 放量突破且周线不弱：可留底仓，但跌回突破位要减。

### 空仓

回答：**现在能不能买？**

常见逻辑：

- 偏弱：不追反弹，等站回压力位并放量。
- 偏强：等回踩支撑缩量企稳，不追高。
- 放量突破：不直接追，等回踩突破位不破。
- 缩量回踩：可重点观察承接，但等放量转强。

### 做T

回答：**如果已经持有，T 的方向怎么配合？**

`/an` 只给大原则：

```
靠近压力减，回踩支撑接；若周线偏弱，T量要小
```

真正的日内 T 点位，仍然用 `/t`：

```
/an 判断：这只票整体能不能做、压力支撑在哪
/t 判断：今天盘中具体卖区和买回区在哪
```

## 图表怎么读

`/an` 的图片是一张多周期综合图：

```
顶部：名称 / 代码 / 综合评级 / 现价涨跌幅
第一栏：日线
第二栏：周线
第三栏：月线
```

每个周期面板包括：

| 图上元素 | 含义 |
|----------|------|
| K线 | 当前周期价格走势 |
| MA5/10/20/60 | 短中期均线结构 |
| BOLL 上中下轨 | 价格通道 |
| 成交量柱 | 当前周期量能强弱 |
| MACD 柱 + DIF/DEA | 动能变化 |
| 金叉/死叉标记 | 最近 MACD 交叉位置 |
| 顶背离/底背离文字 | 动能背离提示 |
| 箱顶/箱底线 | 最近 20 期箱体边界 |
| 压力/支撑线 | 当前周期最近关键位 |
| 量价信号文字 | 放量突破、缩量回踩等结构信号 |

读图顺序建议：

```
1. 先看标题：综合评级和操作风格
2. 看月线：大方向有没有明显问题
3. 看周线：阶段是在修复、主升、震荡还是破位
4. 看日线：当前位置是靠压力还是靠支撑
5. 看成交量和 MACD：确认信号是否有量能和动能配合
```

## 典型解读场景

### 1. 月线强、周线强、日线回踩

含义：大方向还可以，短线只是回踩。

处理：

- 已持仓：看支撑位，不破可以继续观察。
- 空仓：不追高，等缩量回踩后放量转强。
- 做T：靠近日线压力减，回踩日线支撑接。

### 2. 月线强、周线弱、日线反弹

含义：长期没完全坏，但中期有压力，日线反弹可能只是修复。

处理：

- 已持仓：反弹到压力位要观察量能，缩量容易冲高回落。
- 空仓：不要因为日线红一天就追。
- 做T：T量要小，卖出要更果断。

### 3. 月线弱、周线弱、日线底背离

含义：大趋势仍弱，短线可能有反弹，但不是反转。

处理：

- 已持仓：反弹先看减亏，不把底背离当牛市启动。
- 空仓：必须等放量站回关键均线后再评估。
- 做T：只适合轻仓反弹T，不能越跌越补。

### 4. 放量突破前高

含义：出现突破行为，但不是马上无脑追。

处理：

- 先看周线是否支持。
- 回踩前高 / MA20 不破，突破更可信。
- 如果突破后马上缩量回落，可能是假突破。

### 5. 放量跌破前低

含义：价格破位且量能放大，说明不是轻微洗盘。

处理：

- 已持仓优先减风险。
- 空仓不要急着接飞刀。
- 等重新站回破位点，或出现底背离 + 放量阳线。

### 6. 放量滞涨 / 上影压力

含义：有量但价格没涨动，上方有人卖，或者追高资金被套。

处理：

- 压力位附近谨慎。
- 已持仓可考虑减一点。
- 空仓不要追。

## 常见问题

**Q：为什么 `/an` 说偏强，但今天还跌？**  
A：`/an` 是多周期结构判断，不是预测当天涨跌。偏强表示中期结构还没坏，日内波动仍要看 `/t` 或分时。

**Q：为什么 BOLL 下轨有时显示 0？**  
A：极端波动或上市时间较短时，标准差可能让理论下轨变成负数。代码会把下轨截到 0，避免出现无意义负价格。

**Q：为什么箱体有时很宽？**  
A：箱体来自最近 20 期前高/前低。高波动个股或刚经历大涨大跌时，区间会明显变宽，说明当前结构分歧大，不适合用窄幅震荡思路处理。

**Q：为什么有底背离还提示谨慎？**  
A：底背离只说明下跌动能减弱，不代表立刻反转。真正的反转通常还需要放量阳线、站回 MA20 或突破前高确认。

**Q：为什么放量突破还说不追高？**  
A：突破当天追高容易买在分时高点。更稳的做法是等回踩前高、箱顶或 MA20 不破，再确认突破有效。

**Q：`/an` 支持 ETF 吗？**  
A：支持。ETF 价格显示会使用 3 位小数，逻辑仍然是日/周/月多周期分析。

**Q：`/an` 支持港股、美股、商品吗？**  
A：当前主要面向 A股 / ETF。其他品种取决于 `fetchStockKline` 是否能提供足够的日/周/月 K 线数据；数据不足时会提示暂无法多周期分析。

## 局限和注意事项

1. **技术分析不是预测器**  
   `/an` 只能把结构、趋势、量价和关键位整理出来，不能保证未来涨跌。

2. **突发消息无法提前反映**  
   财报、政策、停复牌、黑天鹅事件会直接改变技术结构。

3. **ETF 和低波动品种要降低预期**  
   ETF 的波动比个股小，支撑压力差距很小，不要用个股的涨跌幅预期看 ETF。

4. **背离只是预警，不是买卖点**  
   底背离后可能继续磨，顶背离后也可能继续冲。

5. **箱体会随周期变化**  
   日线箱体适合短线，周线箱体适合波段，月线箱体适合长期结构，不要混用。

```
第一步：/an 代码

第二步：如果 /an 显示结构可观察
  盘中再用 /t 代码

第三步：结合自己的仓位
  已持仓：压力减、支撑接、破位控风险
