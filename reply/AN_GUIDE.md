# `/an` 多周期技术分析指南

> `/an` 用日线、周线、月线整理一只标的的**当前状态、确认条件与风险边界**。它不是预测器，也不提供日内买卖点；盘中做 T 请配合 `/t`。

---

## 命令格式

```text
/an <代码或名称>
/分析 <代码或名称>
/技术分析 <代码或名称>
```

示例：

```text
/an 600519
/an 兆易创新
/an 510300
/an 红利低波
```

## 手机输出：完整文字图，再看技术图

为避免 QQ 的纯文本在手机上难以阅读，`/an` 默认按以下顺序发送两张图：

```text
1. 完整文字分析长图：保留所有结论、多周期结构、关键条件、风险与相对强弱说明
2. 多周期技术图：日线 / 周线 / 月线，供放大核对 K 线、均线、BOLL 与结构区
```

第一张不是摘要卡：原本的完整文字报告会全部排版到图中。先上下滑读完分析，再打开第二张技术图核对结构证据。

## `/an` 和 `/t` 的分工

| 命令 | 解决的问题 | 周期 | 重点 |
|---|---|---|---|
| `/an` | 标的处于什么阶段、是否值得观察、关键条件是什么 | 日/周/月线 | 结构、阶段、确认与失效 |
| `/t` | 今天盘中如何做 T | 分时 + 日线 | 分时结构、均价线、日内高低点、量能 |

```text
先用 /an 定大方向和风险边界
盘中需要做 T 时，再用 /t 定具体节奏
```

## v3.1 核心框架：分层判断，不做线性打分

`/an` 不再使用“日线 30% + 周线 40% + 月线 30%”的线性总分。不同周期的信号不能简单相加：日线金叉不能抵消周线破位，月线偏强也不能让短线破位变成安全。

新的顺序是：

```text
月线：长期许可
  ↓
周线：当前阶段（最重要的约束）
  ↓
日线：当前执行条件
  ↓
风险条件：破位时直接否决或降级
  ↓
量价 / MACD / 背离：确认与预警，不单独决定方向
```

### 月线：长期许可

月线只回答长期背景是否支持参与：

- **长期支持**：长期均线/位置尚可，可关注周线与日线的回踩机会；
- **长期中性**：没有明显长期优势，主要看周线阶段；
- **长期受压**：日线反弹默认先按修复看，不能直接视为趋势反转。

### 周线：当前阶段

周线定义当前最实用的中期状态：

| 周线状态 | 含义 |
|---|---|
| 趋势完整 | 可把日线回踩视为潜在跟随机会 |
| 区间/重建 | 没有单边方向，等待突破或跌破 |
| 弱势修复 | 日线反弹可能只是修复，不宜追高 |
| 结构破坏 | 先控风险，等待重新站回 |

### 日线：执行条件

日线只回答“现在能否行动、还缺什么确认”：

- `突破待确认`：突破后仍需回踩不破；
- `回踩待确认`：回踩参考区后需止跌或转强；
- `区间中部`：不追不抢；
- `弱势缩量整理`：不能把缩量自动理解为承接；
- `短线破位`：优先风险控制。

## 市场状态怎么读

报告顶部会先给出一个市场状态，而不是混合指标后的星级评分：

| 市场状态 | 条件概念 | 操作主线 |
|---|---|---|
| 趋势可持有 | 月线许可、周线支持、日线未破结构 | 持有为主，等回踩确认 |
| 上升趋势中的回踩 | 大结构未坏，日线回踩 | 不追高，等止跌转强 |
| 区间震荡 | 周线未形成单边阶段 | 高抛低吸或等方向 |
| 弱势反弹 | 周线受压，日线出现修复信号 | 不追反弹，压力位观察 |
| 结构转弱 | 日线/周线出现结构破坏 | 控风险，等重新站回 |

### 周期冲突的处理原则

```text
月线或周线受压 + 日线金叉/底背离
= 弱势反弹或修复
≠ 趋势反转
```

只有周线阶段完成改善，日线信号才有资格升级为趋势跟随条件。

## 量价口径

### 日线

日线使用：

```text
当前日成交量 / 近 5 日平均成交量
```

| 量比 | 状态 |
|---|---|
| ≥ 1.5 | 放量 |
| 1.2 ~ 1.5 | 温和放量 |
| 0.8 ~ 1.2 | 正常量 |
| 0.5 ~ 0.8 | 缩量 |
| < 0.5 | 极缩量 |

### 周线和月线

当前周、当前月尚未收线时，累计成交量不能与完整周/月直接比较。因此报告会明确提示：

```text
周线未收线，量能不参与方向判断
月线未收线，量能不参与方向判断
```

这避免把未走完的周期误报为“极缩量”。

### 缩量回踩不是自动买点

只有在日线不处于下降趋势、价格没有跌破当前结构，并且后续出现止跌/转强时，才会提示为“缩量回踩参考区”。

弱势结构中的缩量会写为：

```text
弱势缩量整理，承接未确认
```

它不是低吸建议。

## MA、BOLL、MACD 和背离

### MA / BOLL：位置和结构参考

- `MA5 / MA10 / MA20 / MA60`：观察短中期均线排列与位置；
- `MA20`：重要的中期成本参考，但不是单独的止损位；
- `BOLL`：观察价格通道位置；强趋势可长期贴轨，因此不能单独当买卖点。

### MACD：动能确认，不是主信号

MACD 使用：

```text
EMA12 / EMA26 / DEA9
柱 = (DIF - DEA) × 2
```

MACD 金叉、死叉、红绿柱变化只描述动能：

```text
动能转强 / 动能转弱 / 柱体放大 / 柱体收敛
```

它们不会单独改变最终市场状态。

### 背离：预警，不是反转保证

顶背离和底背离只表示价格与动能不同步。报告会把它标注为：

```text
动能预警
```

底背离仍需放量、站回均线或突破前高等价格结构确认；顶背离也可能在强趋势中持续钝化。

## 趋势质量、波动风险与价格行为

v3.1 在原有多周期结构之上，增加一层**证据质量**。它们用于解释“趋势是否可靠、波动是否可控、突破是否值得跟随”，不会单独推翻月线、周线和日线的结构判断。

| 项目 | 用途 | 不做什么 |
|---|---|---|
| ADX / DMI | ADX 判断是否真有趋势；`+DI/-DI` 看多空主导 | ADX 不预测涨跌，低 ADX 只提示均线信号容易反复 |
| ATR14 | 衡量正常日波动、现价到失效位的风险距离 | 不把 ATR 直接当成固定止损价 |
| 5/20 日均量 | 识别参与度回升、下降或平稳 | 不把缩量自动解读为承接 |
| 收盘强弱 / 吞没 / 窄幅整理 | 归纳 K 线价格行为 | 不堆砌形态名称，不单独给买卖指令 |
| 突破状态 | 区分初步突破、量能确认、回踩确认、假突破和破位 | 突破一根 K 线不等于趋势已经反转 |
| RSI14 | 只在 `≥75` 或 `≤25` 时提示极端过热/超卖 | RSI 不参与市场状态评分 |

报告中的 `趋势与风险质量` 建议这样读：

```text
先看 ADX：无趋势震荡时，均线和金叉更容易来回反复
再看 DMI：多头/空头谁占优
再看 ATR：短线失效位距离是否小于 1 ATR
最后看量能、收盘与突破状态：确认当前动作是否有质量
```

## 相对强弱：和大盘、行业一起看

单只股票上涨不一定强，可能只是跟随大盘；单只股票横住也不一定弱，可能在市场下跌时跑赢。因此 `/an` 增加：

```text
相对沪深300：5 / 20 / 60 日超额收益
相对所属行业：5 / 20 / 60 日超额收益
行业强弱排名：所属东财行业板块当天涨幅名次
```

超额收益计算为：

```text
标的区间收益 - 基准区间收益
```

例如 `20 日超额 -8%`，表示该标的过去 20 个共同交易日比沪深300少涨（或多跌）8 个百分点。

> 个股行业、行业排行、行业日线统一使用东财行业口径，避免把不同供应商的分类名称强行匹配。普通 A 股才显示行业对比；ETF、指数、港美股、行业未识别或映射失败时，只保留相对沪深300，不伪造行业结论。

## 结构参考区、核心价格带和箱体

旧版会同时绘制大箱体、小箱体和中枢，容易重叠、遮挡 K 线，也容易让统计区间看起来像精确交易边界。

v3 将其统一称为**结构参考区**：它们来自近期 K 线实体、常态波幅与分位区间，帮助阅读当前价格所处的位置，但不是天然有效的支撑或压力。

### 图表显示规则

| 周期 | 图中重点 | 规则 |
|---|---|---|
| 日线 | `ZONE-D` 短线参考区 + `BAND` 核心带 | 用于看最近的短线震荡位置 |
| 周线 | `ZONE-W` 阶段参考区 + `BAND` 核心带 | 超过 45% 的宽历史区间不绘制，只保留核心带 |
| 月线 | 不画参考区 | 只看长期均线、BOLL 与 MACD |

`BAND` 是核心价格带：它使用更低透明度的窄横带呈现，不再绘制厚重矩形。图中采用 `ZONE-D`、`ZONE-W`、`BAND` 的短标签，是为了兼容生产环境的裁剪字体；文字报告会给出完整中文解释。

> 超宽的历史区间只是波动背景，不是当前可执行的交易箱体，因此会被隐藏，而不是硬画在图上。

## 关键条件：四种价位不要混淆

报告会分别给出：

| 名称 | 含义 |
|---|---|
| 向上确认 | 站回或突破后，当前判断才允许升级的价格条件 |
| 短线失效 | 当前日线结构被破坏的位置 |
| 波段失效 | 当前周线阶段被破坏的位置 |
| 参考压力/支撑 | 可能遇到抛压或承接的附近区域 |

示例：

```text
向上确认：放量站回 388.30，且后续不跌回
短线失效：跌破 355.55，日线结构转弱
波段失效：跌破 296.25，周线阶段转弱
参考压力：388.30 / 415.41
参考支撑：365.53 / 359.72
```

### 失效位如何计算

失效位绑定当前结构窗口：

- 日线：近 20 日低点与日线短线参考区下沿；
- 周线：近 20 周低点与当前周线参考结构下沿。

它不再简单等于“离现价最近的一条 MA 或 BOLL 下轨”，也不会被更早的极端低点拉得过远。

## 完整文字图阅读顺序

QQ 默认先发完整文字分析长图，建议按以下顺序阅读：

```text
1. 当前判断：趋势、震荡、弱势反弹还是结构转弱
2. 关键条件：向上确认、短线失效、波段失效
3. 趋势与风险：ADX/DMI、ATR 到失效位的距离
4. 相对强弱：相对沪深300、行业排名和行业超额收益
5. 最后打开多周期技术图，核对日/周/月的结构证据
```

## 详细报告阅读顺序

```text
1. 看市场状态：趋势、震荡、弱势反弹还是结构转弱
2. 看主要限制：是月线、周线，还是日线约束了判断
3. 看向上确认：什么发生后才能升级观点
4. 看短线/波段失效：什么发生后必须降级或控风险
5. 最后看量价、MACD、背离和结构参考区作为辅助
```

## 图表阅读顺序

```text
日线：当前执行条件和短线参考区
周线：中期阶段与核心价格带
月线：长期趋势背景
```

每个面板还包含 K 线、MA、BOLL、成交量与 MACD。`VOL PENDING` 表示当前周/月尚未收线，量能不参与方向判断；`BAND ONLY` 表示周线历史区间过宽，因此只保留核心价格带。

## 局限与注意事项

1. 技术分析只能整理结构与条件，不能保证未来涨跌；
2. 财报、政策、停复牌、突发消息可以迅速改变技术结构；
3. ETF 波动较小，参考支撑和压力的间距通常更窄；
4. 背离、金叉、缩量都不是单独买卖点；
5. `/an` 面向 A 股和 ETF 的日/周/月级别分析，盘中具体点位仍应使用 `/t`；
6. 行业排名是东财行业板块**当日涨幅**排名，不等同于主力资金流排名；资金流请用 `/zj`；
7. 相对强弱是历史收益比较，不代表未来会继续跑赢。
