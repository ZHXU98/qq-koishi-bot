# 做T参谋使用指南

> `/t` 命令：基于实时分时数据 + 日线结构，给出当前股价的做T位置建议与分析。  
> 不是计算器，而是告诉你**现在在哪、卖在哪、买在哪、为什么**。

---

## 命令格式

```
/t <代码或名称>          自动判断形态（推荐）
/t <代码或名称> -sw      强制按震荡模式分析
/t <代码或名称> -tr      强制按单边趋势模式分析
```

例：
```
/t 600519
/t 贵州茅台 -sw
/t 宁德时代 -tr
```

---

## ⏰ 三阶段：纯竞价 → 开盘确认 → 盘中

机器人自动识别当前阶段，**不同阶段用不同的判断基准**：

| 阶段 | 判定 | 做什么 |
|------|------|--------|
| **纯竞价** | 分时 < 5 根（≈9:35前） | 只给竞价分析（高开/低开/量比），**不给T位**，等方向确认 |
| **开盘确认** | 5 ≤ 分时 < 30 根（≈10:00前） | 用**轨迹+量能+振幅阈值**判断做T场景，给动态T位 |
| **盘中** | 分时 ≥ 30 根 | 黄线偏离 + 轨迹 + 量能 + 前高前低 + 5分钟结构；MACD仅过滤 |

**为什么开盘不能用黄线？**
- 黄线 = 今日累计成交额 ÷ 累计成交量，开盘几分钟数据极少，几乎等于开盘价本身
- 此时用黄线算"偏离度"毫无意义
- 但**开盘恰恰是最重要、T 差最大的时段**——高开冲高是卖出良机，低开恐慌是买回良机

**为什么纯竞价不给T位？**
- 9:25竞价只告诉"跳空多少"，9:30一开盘就能看到
- 但"高开2%"之后是继续涨还是回落，**只有开盘后5分钟才知道**
- 竞价是**观点**，开盘走势才是**事实**——先等事实

---

## ⭐ 核心：先高后走低 / 先低后走高（轨迹识别）

做T最值钱的窗口是"**先冲高后回落**"（卖出）和"**先砸低后企稳**"（买回）。识别它必须看**轨迹**而非快照：

```
先高后走低（卖T）的判断：
  ① 今日高点较今开冲高 ≥ 1%      → 说明真的冲高过
  ② 现价从高点回落 ≥ 确认阈值     → 说明正在回落（即使仍在今开上方）
  ①+② → 「冲高回落」确认，T卖出信号

先低后走高（买T）的判断：
  ① 今日低点较今开下探 ≥ 1%      → 说明真的砸出过低点
  ② 现价自低点回升 ≥ 确认阈值     → 说明正在修复（即使仍在今开下方）
  ①+② → 「低开企稳」确认，T买回信号
```

**振幅自适应确认阈值**（波动大的票，回落要更深才当真）：

```
确认阈值 = max(0.8%, 今日振幅 × 25%)

振幅1%（银行股）  → 阈值0.8%（全天就这么点波幅）
振幅3%（正常股）  → 阈值0.8%
振幅5%（活跃股）  → 阈值1.25%
振幅8%（妖股）    → 阈值2.0%（妖股2%回落太平常，不算数）
```

## 🔍 开盘六大场景（轨迹 × 量能）

开盘5分钟后，先看**缺口方向**（高/低/平开），再看**轨迹**（从高点回落/从低点回升），叠加**量能**：

| 场景 | 识别条件 | 含义 | 操作 |
|------|---------|------|------|
| 🔻 高开回落 | 高开 + 从高点回落≥阈值 | 竞价是假象，有人出货 | 反抽到今开附近 T出（放量=出货真，缩量=可能是洗盘） |
| 🚀 高开续涨 | 高开 + 未出现有效回落 | 抢筹是真的 | **别T**，卖出位抬到+2%~4%，防踏空 |
| 🟢 低开企稳 | 低开 + 自低点回升≥阈值 | 恐慌已释放，有资金接 | 回踩今开下方分批买回（缩量=抛压枯竭） |
| 🔴 低开续跌 | 低开 + 未有效回升 | 恐慌是真的，单边杀 | **别T**，优先减仓，等缩量止跌、5分钟转强并站回均价线 |
| ↗️ 平开走强 | 平开 + 走强 | 无缺口但资金进 | T位上移 |
| ↘️ 平开走弱 | 平开 + 走弱 | 无缺口但资金出 | T位下移 |

## ⏱ 开盘做T：分钟分阶段确认

开盘的价格结构、量能和均价线先于 MACD 成熟；日内 MACD 又从当天首根 K 线开始计算，因此不能在最早几分钟把一次交叉当成交易信号。

| 有效分钟K数 | 时间参考 | 关注重点 | MACD 使用规则 | 做T动作 |
|---|---:|---|---|---|
| **≤ 3 根** | 约 9:30~9:32 | 首根实体方向、分时均价线、量比/成交量 | **不看 MACD** | 不给 T 位，不追第一波 |
| **4~5 根** | 约 9:33~9:34 | 高低点轨迹、是否站上/跌破均价 | 只观察绿柱是否收敛、DIF 是否拐头 | 仍不把 MACD 当确认信号 |
| **6~10 根** | 约 9:35~9:39 | 均价线方向、量价、开盘轨迹、5分钟结构 | 可同步参考，不作条件 | 均价线上方突破前高、5分钟转强才考虑买回；跌破均价/前低且5分钟转弱才考虑减仓 |
| **> 10 根** | 约 9:40 后 | 黄线偏离、轨迹、量能、前高前低、5分钟结构 | 可同步参考，不作条件 | 按价格行为主信号执行 T 位 |

> 0 轴位置可帮助阅读 MACD 所处位置，但不影响做T信号是否成立；均价线、前高前低、量能和 5 分钟结构始终优先。

## 🎯 价格行为主信号：单层触发

`/t` 不把 MACD 当作买卖开关。MACD 本身滞后，尤其是开盘前十分钟；真正的交易触发来自价格和成交量已经发生的变化。

| 主信号 | 买回侧观察 | T出 / 减仓侧观察 |
|---|---|---|
| **均价线突破/回踩** | 站回均价线，回踩不破 | 跌破均价线，反抽受压 |
| **量能突变** | 下跌缩量止跌，或站上均价线时放量 | 跌破均价线/前低时放量；冲高缩量乏力 |
| **前高前低突破** | 突破近20分钟前高后回踩不破 | 跌破近20分钟前低，先防守不抄底 |
| **5分钟K线结构** | 近5根形成阳线结构 | 近5根形成阴线结构 |

系统把这四类条件评分：同侧 **≥3 分**才标记为价格行为触发。这样避免单次刺穿均价线、单根放量或单一形态就直接做T。

**MACD 的职责是辅助参考：** 它不负责发现机会、触发交易或否决已经成立的价格行为信号。均价线、量能、前高前低、5分钟结构形成做T建议后，MACD 同向出现只作为补充信息；没有同向 MACD 时，仍按价格行为执行。

## 📉 分时MACD（1分钟级别，辅助参考）

**同花顺分时日内口径**：用**当天** 1 分钟 K 线算 MACD，参数为 **(12, 26, 9)**。EMA 初始值取当天第一根 1 分钟 K 线的收盘价；不跨交易日取数，因此隔夜跳空不会被当作日内一分钟波动写进 MACD。图上和文字都只展示、只分析当天序列。

**为什么保留 MACD：** 它只是一个描述动能状态的附加视角，可与价格行为一起阅读，但不参与做T规则的触发和分档。核心顺序是：**均价线/量能/前高前低/5分钟结构形成唯一的价格行为信号；MACD仅供旁路参考。**

| MACD状态 | 含义 | 配合动作 |
|---------|------|---------|
| 水上金叉 | 动能偏强 | 仅作辅助参考；价格行为已偏强时可一并观察，**不能单独追买** |
| 水下金叉 | 弱势修复 | 仅作辅助参考；不取代均价线、前高和量能信号 |
| 水上死叉 | 强势动能转弱 | 仅作辅助参考；价格行为同时走弱时可一并观察，**不能单独卖** |
| 水下死叉 | 弱势仍在 | 仅作辅助参考；不追杀，仍等前低、均价线和量能的价格行为信号 |
| ⚠️ 顶背离（价格新高、MACD没新高） | 动能可能减弱 | 仅作辅助参考，非单独卖点 |
| 🟢 底背离（价格新低、MACD没新低） | 跌势可能衰竭 | 仅作辅助参考，非单独买点 |

图上 MACD 面板也做了同花顺风格优化：

- 红/绿柱以零轴展开；
- DIF 使用蓝线，DEA 使用黄线；
- 面板高度和线宽加大，避免线太窄看不清；
- 缩放同时参考 DIF、DEA、柱体，避免只按柱体缩放导致线贴边或失真。
- MACD 仅使用当天 1 分钟数据，参数为 `(12, 26, 9)`；第一根收盘价同时作为快线与慢线 EMA 的初始值。

**决策顺序：** 均价线突破/回踩 + 量能 + 前高前低 + 5分钟结构形成唯一的做T信号；MACD仅同步展示，供人工辅助阅读。

## 什么是做T？

A股是 **T+1 制度**：今天买的股票，最晚明天才能卖出。  
但今天持有的"老仓"可以随时卖出，再在当日低位买回同等数量——  
这个"高卖低买降均价"的操作，就叫**做T**。

**核心逻辑：**
```
持有 10000 股 @ 均价 20 元
→ 上午涨到 20.6 卖出 2000 股
→ 下午跌回 20.2 买回 2000 股
→ 还是持有 10000 股，但均价从 20 降到了约 19.94
→ 纯靠差价降低了持仓成本，不需要额外资金
```

> ⚠️ T量不能超过"老仓"持仓量，否则会变成隔日平仓（T+1 限制）。

## 两种做T模式

### 震荡模式（-sw / swing）

**适合什么情况：**
- 股价在一个相对稳定的区间内来回波动
- 均线粘合，没有明显方向
- BOLL 带宽收窄，通道变细

**操作节奏：**
```
高点（偏离黄线 +1.5% 以上）→ 卖出
低点（偏离黄线 -1% 以下）  → 买回
```

**预期T差：** BOLL 带宽的 30%~50%（今日可操作空间）

---

### 单边模式（-tr / trend）

**上升单边（多头排列 MA5 > MA10 > MA20）：**
- ⚠️ **整体不建议做T**，很容易踏空
- 如坚持：每次T量不超持仓 20%，买回位设在 MA5，绝不等黄线
- 止损：日内低点跌破即认亏

**下降单边（空头排列 MA5 < MA10 < MA20）：**
- 可做"反弹T"：等价格反弹至黄线上方 +0.5% 以上卖出
- 买回等缩量再创低，不追杀跌（量不缩不买）
- ⚠️ 下降趋势中做T是高风险操作，须严格控制T量

## 核心指标解读

### 黄线（分时均价线）

分时图里那条黄色的线，是**今日所有成交的加权平均价格**。

```
黄线 = 今日累计成交额 ÷ 今日累计成交量
```

**为什么黄线重要？**
- 高于黄线 → 当前持有者平均在亏（有意愿出货压力）
- 低于黄线 → 当前持有者平均在盈（市场偏强）
- 黄线本身是日内最强支撑/压力位之一

| 偏离度 | 含义 | 做T意义 |
|--------|------|---------|
| > +2% | 价格明显高于今日平均成本 | T的卖出窗口 |
| +0.5%~+2% | 轻微偏贵 | 可挂单等待更高位 |
| -0.5%~+0.5% | 均值附近 | T的空间很小，不划算 |
| -0.5%~-2% | 轻微偏便宜 | 接近买回窗口 |
| < -2% | 价格明显低于今日平均成本 | T的买回机会，注意量能 |

---

### 量能节奏

| 当前量 vs 均量 | 含义 |
|--------------|------|
| 当前分钟量 > 均量 150% | 放量，有主动买/卖力量介入 |
| 当前分钟量 80%~150% | 正常量 |
| 当前分钟量 < 80% | 缩量，主动交易减少 |

**关键组合：**
- 🔴 价涨 + 缩量 → 上涨乏力，T的卖出信号（没人追高）
- 🔴 价格偏离黄线 +1.5%+ + 缩量 → **强卖出信号**
- 🟢 价跌 + 缩量 → 下跌钝化，T的买回信号（没人继续砸）
- 🟢 价格偏离黄线 -1%+ + 缩量 → **强买回信号**
- ⚠️ 价涨 + 放量 → 趋势性上攻，不要T，跟涨

---

### BOLL 布林带（日线）

由 20 日均线（中轨）± 2倍标准差 构成的"价格通道"。

```
上轨 = MA20 + 2σ（偏贵区间上限）
中轨 = MA20（价值中枢）
下轨 = MA20 - 2σ（偏便宜区间下限）
带宽 = (上轨 - 下轨) / 中轨 × 100%
```

| 带宽 | 市场状态 | 做T适合度 |
|------|---------|----------|
| < 5% | 极度收窄，即将变盘 | ⭐⭐ 谨慎，空间小 |
| 5%~10% | 正常震荡 | ⭐⭐⭐⭐ 最适合做T |
| 10%~15% | 趋势扩张 | ⭐⭐ 需配合趋势方向 |
| > 15% | 强趋势，大幅波动 | ⭐ 高风险，不建议 |

---

### 均线排列（日线判断形态）

| 排列 | 判断 | 做T策略 |
|------|------|---------|
| MA5 > MA10 > MA20 | 多头排列（上升单边）| 不建议做T，跟涨优先 |
| MA5 < MA10 < MA20 | 空头排列（下降单边）| 谨慎做T，反弹T |
| 三线粘合（差 < 2%）| 震荡整理 | 积极做T，高卖低买 |
| MA5 上穿 MA10/MA20 | 金叉，趋势转涨 | 减少做T量 |
| MA5 下穿 MA10/MA20 | 死叉，趋势转跌 | 减少做T量 |

## T位计算方法

### 基准价：分阶段选择

```
开盘确认阶段（5~30根）：基准 = 今开（黄线不可靠）
盘中阶段（≥30根）：      基准 = 分时均价（黄线）
```

### 开盘阶段 T 位（场景阈值 × 日线形态微调）

路径：**场景定区间 → 日线形态抖动调整**

| 场景 | 卖出区（基准=今开） | 买回区（基准=今开） |
|------|---------------------|---------------------|
| 🔻 高开回落 | +0.3% ~ +1.2%（反抽即出） | -0.8% ~ -2.0%（回落接） |
| 🚀 高开续涨 | +2.0% ~ +4.0%（等明显冲高） | -0.3% ~ -1.0%（浅回踩接） |
| 🟢 低开企稳 | +0.5% ~ +1.5%（反弹至今开附近） | -0.3% ~ -1.2%（回踩接） |
| 🔴 低开续跌 | +0.0% ~ +0.8%（反抽稳就出） | -2.0% ~ -4.0%（等量极缩） |

日线形态微调：
- **下降单边**：卖出更积极（-0.2~0.3%），买回更保守（+0.3~0.5%）
- **上升单边**：卖出更保守（+0.3~0.5%），买回更积极（-0.2~0.3%）

### 盘中阶段 T 位（黄线偏离）

```
卖出下限 = 黄线 × (1 + 偏离阈值_低)   // 震荡: 1.5%，趋势: 0.8%
卖出上限 = min(日线BOLL上轨, 黄线 × (1 + 偏离阈值_高))  // 震荡: 2.8%，趋势: 1.5%
买回上限 = 黄线 × (1 - 偏离阈值_低)   // 震荡: 0.8%，趋势: 0.3%
买回下限 = max(日低, 黄线 × (1 - 偏离阈值_高))  // 震荡: 1.8%，趋势: 1.0%
```

### 手续费（双边成本估算）

**个股（万0.8，无免五）：**
```
买入手续费：万0.8（无最低门槛，按实际计）
卖出手续费：万0.8
印花税（卖出）：千1（单向）
过户费（沪市）：万0.2 × 双向 = 万0.4

双边总成本 ≈ 0.30%（万0.8×2 + 千1 + 万0.4）
```

**ETF（万0.1，免五，无印花税，无过户费）：**
```
买入手续费：万0.1（免五，最低5元但ETF够量通常不触发）
卖出手续费：万0.1
印花税：无（ETF 免印花税）
过户费：无（ETF 免过户费）

双边总成本 ≈ 0.02%（万0.1×2）
```

> 做T差价需覆盖手续费才有意义：个股振幅 < 0.45% 不建议操作；ETF 振幅 < 0.08% 不建议操作。

## 常见问题

**Q：为什么机器人判断是"震荡"，但我感觉明显在涨？**  
A：机器人基于日线近20日数据判断，"震荡"是指中期结构无趋势。短期1-2日的涨跌不代表中期方向，日线均线排列是更稳定的参考。

**Q：T的数量应该多少？**  
A：通常建议 10%~30% 的仓位。太少，降成本效果微弱；太多，一旦买不回来，被迫空仓踏空。

**Q：买回没买到怎么办？**  
A：卖出后当日收盘前未买回，明日变成空仓（减仓了）。这也是做T的主要风险——**卖出容易，买回要耐心**。不要因为没买到就追高，宁可等下一个机会。

**Q：下降趋势中做T有意义吗？**  
A：有，但风险高。每次T只能降一点点成本，但如果继续大跌，降的那点均价远不够。下降趋势中更重要的是判断是否该止损，而不是拼命做T。
