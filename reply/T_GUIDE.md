# 做T参谋使用指南

> `/t` 命令：基于实时分时数据 + 日线结构，给出当前股价的做T位置建议与分析。  
> 不是计算器，而是告诉你**现在在哪、卖在哪、买在哪、为什么**。

---

## 命令格式

```
/t <代码或名称>          自动判断形态（推荐）
/t <代码或名称> -sw      强制按震荡模式分析
/t <代码或名称> -tr      请求按单边趋势分析（仅当日线已确认上涨/下降方向时生效）
```

例：
```
/t 600519
/t 贵州茅台 -sw
/t 宁德时代 -tr
```

## 手机输出：完整文字图，再看分时图

为避免 QQ 的纯文本在手机上难以阅读，`/t` 默认按以下顺序发送两张图：

```text
1. 完整文字分析长图：保留形态、分时现状、价格行为、MACD、T位与当前操作建议
2. 分时技术图：价格线、均价线、成交量、MACD 与 T 位标注
```

第一张不是摘要卡：原本的完整文字报告会全部排版到图中。第二张分时技术图标题下方会同步显示与第一张**完全同源**的“当前操作建议 / 等待条件”；两张图共用同一决策结果，技术图其余部分用于核对均价线、5 分钟结构、价格区间和 MACD 证据。

## ⏰ 三阶段：纯竞价 → 开盘确认 → 盘中

机器人自动识别当前阶段，**不同阶段用不同的判断基准**：

| 阶段 | 判定 | 做什么 |
|------|------|--------|
| **纯竞价 / 快讯** | 分时 ≤ 3 根（约 9:30~9:32） | 只给竞价分析（高开/低开/量比），**不给完整T位**；仅明确结构可给10%~15%小仓方向 |
| **开盘观察** | 4~5 根（约 9:33~9:34） | 看首段高低点、均价线、量能和初步5分钟结构，暂不触发完整做T |
| **开盘确认** | 6~30 根（约 9:35~10:00） | 用**开盘场景 + 轨迹 + 量能 + 日线形态**计算动态T位；评分只作区间内确认 |
| **盘中** | 分时 ≥ 31 根（约 10:00 后） | 黄线方向 + 偏离、轨迹、量能、前高前低 + 真实1分钟OHLC聚合结构；MACD仅同步展示 |

> **实时数据边界：** 黄线继续使用分时累计成交额/成交量；价格行为使用同一分钟的真实 OHLC。最新尚未完成的一分钟只用于显示实时价格和当前位置，不参与分钟量、5分钟结构、回踩确认等完整周期统计。所有盘中判断只使用当前时刻已经产生的数据。

**为什么开盘不能用黄线？**
- 黄线 = 今日累计成交额 ÷ 累计成交量，开盘几分钟数据极少，几乎等于开盘价本身
- 此时用黄线算"偏离度"毫无意义
- 但**开盘恰恰是最重要、T 差最大的时段**——高开冲高是卖出良机，低开恐慌是买回良机

> 日线基础模式和近10日振幅只使用昨日及更早的完整日K，避免上午未完成日K让模式和波动基准来回变化；今日已知分时只负责实时动作。

**为什么纯竞价不给T位？**
- 9:25竞价只告诉"跳空多少"，9:30一开盘就能看到
- 但"高开2%"之后是继续涨还是回落，**只有开盘后5分钟才知道**
- 竞价是**观点**，开盘走势才是**事实**——先等事实

## ⭐ 核心：先高后走低 / 先低后走高（轨迹识别）

做T最值钱的窗口是"**先冲高后回落**"（卖出）和"**先砸低后企稳**"（买回）。识别它必须看**轨迹**而非快照：

```
先高后走低（卖T）的判断：
  ① 今日高点较今开冲高 ≥ 1%      → 说明真的冲高过
  ② 现价从高点回落 ≥ 确认阈值     → 说明正在回落（即使仍在今开上方）
  ①+② → 「冲高回落」确认，T卖出信号

先低后走高（买T）的判断：
  ① 今日低点较今开下探 ≥ 1%      → 说明真的砸出过低点
  ② 现价自低点回升 ≥ 确认阈值     → 说明正在修复（即使仍在今开下方）
  ①+② → 「低开企稳」确认，T买回信号
```

**振幅自适应确认阈值**（波动大的票，回落要更深才当真）：

```
确认阈值 = max(0.8%, 今日振幅 × 25%)

振幅1%（银行股）  → 阈值0.8%（全天就这么点波幅）
振幅3%（正常股）  → 阈值0.8%
振幅5%（活跃股）  → 阈值1.25%
振幅8%（妖股）    → 阈值2.0%（妖股2%回落太平常，不算数）
```

## 🔍 开盘六大场景（轨迹 × 量能）

开盘5分钟后，先看**缺口方向**（高/低/平开），再看**轨迹**（从高点回落/从低点回升），叠加**量能**：

| 场景 | 识别条件 | 含义 | 操作 |
|------|---------|------|------|
| 🔻 高开回落 | 高开 + 从高点回落≥阈值 | 竞价是假象，有人出货 | 反抽到今开附近 T出（放量=出货真，缩量=可能是洗盘） |
| 🚀 高开续涨 | 高开 + 未出现有效回落 | 抢筹是真的 | **别T**，卖出位抬到+2%~4%，防踏空 |
| 🟢 低开企稳 | 低开 + 自低点回升≥阈值 | 恐慌已释放，有资金接 | 回踩今开下方分批买回（缩量=抛压枯竭） |
| 🔴 低开续跌 | 低开 + 未有效回升 | 恐慌是真的，单边杀 | **别T**，优先减仓，等缩量止跌、5分钟转强并站回均价线 |
| ↗️ 平开走强 | 平开 + 走强 | 无缺口但资金进 | T位上移 |
| ↘️ 平开走弱 | 平开 + 走弱 | 无缺口但资金出 | T位下移 |

## ⏱ 开盘做T：分钟分阶段确认

开盘的价格结构、量能和均价线先于 MACD 成熟；日内 MACD 又从当天首根 K 线开始计算，因此不能在最早几分钟把一次交叉当成交易信号。

| 有效分钟K数 | 时间参考 | 关注重点 | MACD 使用规则 | 做T动作 |
|---|---:|---|---|---|
| **≤ 3 根** | 约 9:30~9:32 | 缺口、首根实体、今开价、早盘均价、首段高低点与量比 | 不参与 | 启用“开盘快讯”：仅在明确的冲高兑现/恐慌收回时给 **10%~15% 小仓方向**；其余观察 |
| **4~5 根** | 约 9:33~9:34 | 首段高低点、均价线相对位置、量能变化、初步5分钟结构 | 仅同步展示，不参与规则 | 继续观察，不提前给 T 信号 |
| **6~30 根** | 约 9:35~10:00 | 开盘场景、均价线突破/回踩、量能、前高前低、5分钟结构 | 仅同步展示，不参与规则 | 价格行为评分 ≥3 分后，仍须先满足对应T区间与开盘场景约束 |
| **≥31 根** | 约 10:00 后 | 黄线方向 + 偏离、轨迹、量能、前高前低、5分钟结构 | 仅同步展示，不参与规则 | 先确认处在匹配的买/卖区，再按黄线方向过滤，最后由价格行为评分确认 |

### 黄线方向优先（盘中）

黄线不是静态中轴。系统观察最近 15 分钟黄线累计变化，变化达到 **±0.12%** 才判定为有方向，过滤自然漂移噪音：

| 黄线状态 | T 位含义 | 操作约束 |
|---|---|---|
| **↘️ 下行** | 黄线是动态压力；卖出区收紧至黄线附近；绿色区为“止跌观察区” | 不因价格低而买回。仅在黄线走平/上拐、重新站稳黄线、5分钟结构转强后考虑接回；优先等反抽黄线失败做反弹 T。 |
| **➡️ 走平** | 标准双向震荡区间 | 卖出区与买回区均须配合价格行为确认。 |
| **↗️ 上行** | 黄线是动态支撑；卖出区上移为“兑现区”；买回位贴近黄线 | 不因一次回落追卖。只有进入兑现区且冲高回落/跌回黄线确认，才小仓 T 出；回踩上行黄线企稳才考虑接回。 |

> **操作优先级：** 开盘强风险场景 → 对应买/卖区的位置许可 → 黄线方向过滤 → 价格行为评分确认 → MACD旁路说明。卖出区内不追买，买回区内不追卖；中性区出现评分时只记录短线转强/转弱，等待价格回到对应区间。

> 开盘优化的重点是避免“等所有指标同时满足”而错过位置：从第 6 根分钟 K 起，系统只计算一套价格行为评分。均价线突破/回踩、量能、前高前低、5 分钟结构中，同侧条件累计达到 3 分，作为**已进入对应区间后**的确认；MACD 无论是否出现、是否同向，均不改变该建议。

### 完整决策矩阵：阶段 → 位置 → 黄线 → 评分

> `/t` 的“买回 / T出”不是单指标结论。系统先确定当前阶段和可操作位置，再做趋势过滤，最后才让价格行为评分确认；表中“观察”均表示不新增 T 仓，等待下一条件满足。

#### 1. 阶段优先级

| 当前阶段 | 条件 | 最终处理 | 是否生成完整T位 |
|---|---|---|---|
| 纯竞价 / 快讯 | ≤3 根有效分钟K | 仅在“冲高失守今开”或“低开后收回今开与早盘均价”时给 10%~15% 小仓方向；其他均观察 | 否 |
| 开盘观察 | 4~5 根 | 只补全首段高低点、量能和均价结构；不由评分直接操作 | 否 |
| 开盘确认 | 6~30 根 | 先由高开回落、高开续涨、低开企稳、低开续跌或平开场景计算今开基准T区 | 是 |
| 盘中 | ≥31 根 | 以黄线为基准计算买回区、卖出区，并使用黄线方向过滤 | 是 |

#### 2. 有完整T位时的位置 × 评分矩阵

| 当前位置 | 价格行为评分 | 最终建议 | 现实含义 |
|---|---|---|---|
| 卖出区 | 卖出评分 ≥3 | **允许分批T出 / 减仓** | 已到相对高位，且均价线、前低、5分钟结构、量能中至少多项转弱 |
| 卖出区 | 买入评分 ≥3 | **不追买**，等回落到买回区 | 高位转强不能改变“高卖低买”的 T 仓纪律 |
| 卖出区 | 无评分 | 等走弱确认 | 位置合适但没有转弱结构，不机械卖出 |
| 买回区 | 买入评分 ≥3 | **允许分批买回**，但仍受下行黄线限制 | 已到相对低位，且出现止跌/转强共振 |
| 买回区 | 卖出评分 ≥3 | **不追卖**，等反弹到卖出区 | 低位走弱不应在 T 买回区扩大卖出 |
| 买回区 | 无评分 | 等止跌 / 转强确认 | 位置合适但没有结构，不机械抄底 |
| 中性区 | 买入评分 ≥3 | **不追买**，记录转强，等回踩买回区 | 多数买入评分发生在站回黄线或突破前高后，属于确认而非低吸位置 |
| 中性区 | 卖出评分 ≥3 | **不追卖**，记录走弱，等反弹卖出区 | 多数卖出评分发生在跌破黄线或前低后，属于确认而非高卖位置 |
| 中性区 | 无评分 | 持有观察 | 既无价格位置，也无结构共振 |

#### 3. 黄线方向过滤（仅盘中 ≥31 根）

| 黄线方向 | 判定 | 对卖出区的处理 | 对买回区的处理 |
|---|---|---|---|
| ↘️ 下行 | 近15分钟累计变化 ≤ -0.12% | 反弹到黄线附近的卖出区可优先观察；仍等走弱确认 | **止跌观察区，不自动买回**；必须先见黄线走平/上拐、站回黄线和5分钟转强 |
| ➡️ 走平 | 近15分钟变化在 -0.12% ~ +0.12% | 标准震荡卖出区，等走弱确认 | 标准震荡买回区，等转强确认 |
| ↗️ 上行 | 近15分钟累计变化 ≥ +0.12% | **兑现区，不因普通回落追卖**；进入区间后仍需冲高回落或跌回黄线确认 | 回踩上行黄线附近企稳后才考虑接回，避免等待过深 |

#### 4. 强风险覆盖规则

| 条件 | 覆盖结果 |
|---|---|
| 开盘 6~30 根且识别为“低开续跌” | 优先防守，不建议做T；等缩量止跌、5分钟转强并重新站回均价线 |
| 日线为上升单边 | 即便区间和评分满足，也建议小T仓（≤20%），防止踏空 |
| 日线为下降单边 | 以反弹T为主，建议小T仓（≤15%），不把买回当成趋势反转 |
| 当日振幅低于成本阈值 | 不强求做T：个股 <0.45%，ETF <0.08% 时优先放弃 |

#### 5. 两张图的同源操作建议

第一张文字长图与第二张分时技术图不分别计算操作建议。代码先通过同一个 `resolveTAction()` 按上述优先级生成“当前怎么做 / 等什么条件”，再同时传给两张图：

```text
同一份 timeInfo + tPos
→ resolveTAction()
→ 文字长图“当前操作建议”
→ 技术图标题下方“操作建议条”
```

因此，第二张图的操作建议条是第一张建议的可视化核对入口，不是新增指标或第二个信号系统。

#### 6. MACD 的固定边界

MACD（金叉、死叉、顶背离、底背离）只描述日内动能，**不生成交易许可，不覆盖位置约束，不推翻黄线方向过滤**。例如：卖出区内的死叉仍需价格行为确认；买回区内的金叉仍不能覆盖黄线持续下行。

### 前 3 分钟开盘快讯：只抓明确的结构

前 3 分钟不是“不能做”，但不能套用盘中 T 区间或 5 分钟评分。`/t` 只在有效分钟 K 为 **2~3 根** 时启动开盘快讯，并且只给 **10%~15% 老仓 / 预留T仓** 的小仓方向：

| 结构 | 触发条件 | 快讯动作 | 失效条件 |
|---|---|---|---|
| **高开冲高兑现** | 高开或先冲高 ≥0.6%，随后失守今开，且出现降低高点或跌破早盘均价 | 小仓 T 出 | 重新站回今开并止跌，停止继续卖 |
| **低开恐慌收回** | 低开或先下探 ≥0.6%，随后同时收回今开与早盘均价 | 小仓买回 | 再次失守今开或早盘均价，停止继续买 |
| **开盘承接强** | 守住今开与早盘均价，且出现抬高低点或接近首段高点 | 持有观察，避免过早 T 出 | 跌破今开/均价后重新评估 |
| **其他情况** | 方向、量能或高低点没有明确关系 | 暂不操作 | 等第4~5分钟补全结构 |

> 这个快讯不输出完整 T 区间，也不使用 MACD。它的目的只是利用开盘最有价值、但持续最短的“竞价兑现 / 恐慌收回”窗口；若不满足明确结构，宁可等第 6 根分钟 K 后的单层价格行为评分。

## 🎯 价格行为主信号：单层触发

`/t` 不把 MACD 当作买卖开关。MACD 本身滞后，尤其是开盘前十分钟；真正的交易触发来自价格和成交量已经发生的变化。

| 主信号 | 买回侧观察 | T出 / 减仓侧观察 |
|---|---|---|
| **均价线突破/回踩** | 站回均价线，回踩不破 | 跌破均价线，反抽受压 |
| **量能突变** | 下跌缩量止跌，或站上均价线时放量 | 跌破均价线/前低时放量；冲高缩量乏力 |
| **前高前低突破** | 突破近20分钟前高后回踩不破 | 跌破近20分钟前低，先防守不抄底 |
| **5分钟K线结构** | 近5根形成阳线结构 | 近5根形成阴线结构 |

系统把这四类条件评分：同侧 **≥3 分**才标记为价格行为确认。同一分钟的均价线突破与回踩确认互斥，回踩必须在此前已连续站稳/受压后再发生，避免单一均价线事件重复得分。确认不等于任何位置都交易：必须先进入对应的买回区或卖出区，并通过黄线方向的趋势过滤；否则仅提示短线转强/转弱，等待位置。

**MACD 的职责是辅助参考：** 它不负责发现机会、触发交易或否决已经成立的价格行为信号。均价线、量能、前高前低、5分钟结构形成做T建议后，MACD 同向出现只作为补充信息；没有同向 MACD 时，仍按价格行为执行。

## 📉 分时MACD（1分钟级别，辅助参考）

**同花顺分时日内口径**：用**当天已完成的** 1 分钟 K 线算 MACD，参数为 **(12, 26, 9)**。EMA 初始值取当天第一根 1 分钟 K 线的收盘价；不跨交易日取数，因此隔夜跳空不会被当作日内一分钟波动写进 MACD。最近 10 个分钟内的交叉才显示为金叉/死叉，更早交叉不再作为当前事件强调；DIF/DEA 与柱体状态仍继续展示。

**为什么保留 MACD：** 它只是一个描述动能状态的附加视角，可与价格行为一起阅读，但不参与做T规则的触发和分档。核心顺序是：**均价线/量能/前高前低/5分钟结构形成唯一的价格行为信号；MACD仅供旁路参考。**

| MACD状态 | 含义 | 配合动作 |
|---------|------|---------|
| 水上金叉 | 动能偏强 | 仅作辅助参考；价格行为已偏强时可一并观察，**不能单独追买** |
| 水下金叉 | 弱势修复 | 仅作辅助参考；不取代均价线、前高和量能信号 |
| 水上死叉 | 强势动能转弱 | 仅作辅助参考；价格行为同时走弱时可一并观察，**不能单独卖** |
| 水下死叉 | 弱势仍在 | 仅作辅助参考；不追杀，仍等前低、均价线和量能的价格行为信号 |
| ⚠️ 顶背离（价格新高、MACD没新高） | 动能可能减弱 | 仅作辅助参考，非单独卖点 |
| 🟢 底背离（价格新低、MACD没新低） | 跌势可能衰竭 | 仅作辅助参考，非单独买点 |

图上 MACD 面板也做了同花顺风格优化：

- 红/绿柱以零轴展开；
- DIF 使用蓝线，DEA 使用黄线；
- 面板高度和线宽加大，避免线太窄看不清；
- 缩放同时参考 DIF、DEA、柱体，避免只按柱体缩放导致线贴边或失真。
- MACD 仅使用当天 1 分钟数据，参数为 `(12, 26, 9)`；第一根收盘价同时作为快线与慢线 EMA 的初始值。

**决策顺序：** 均价线突破/回踩 + 量能 + 前高前低 + 5分钟结构形成唯一的做T信号；MACD仅同步展示，供人工辅助阅读。

## 什么是做T？

A股是 **T+1 制度**：今天买的股票，最晚明天才能卖出。  
但今天持有的"老仓"可以随时卖出，再在当日低位买回同等数量——  
这个"高卖低买降均价"的操作，就叫**做T**。

**核心逻辑：**
```
持有 10000 股 @ 均价 20 元
→ 上午涨到 20.6 卖出 2000 股
→ 下午跌回 20.2 买回 2000 股
→ 还是持有 10000 股，但均价从 20 降到了约 19.94
→ 纯靠差价降低了持仓成本，不需要额外资金
```

> ⚠️ T量不能超过"老仓"持仓量，否则会变成隔日平仓（T+1 限制）。

---

## 两种做T模式

### 震荡模式（-sw / swing）

**适合什么情况：**
- 股价在一个相对稳定的区间内来回波动
- 均线粘合，没有明显方向
- BOLL 带宽收窄，通道变细

**操作节奏：**
```
高点（偏离黄线 +1.5% 以上）→ 卖出
低点（偏离黄线 -1% 以下）  → 买回
```

**预期T差：** BOLL 带宽的 30%~50%（今日可操作空间）

---

### 单边模式（-tr / trend）

**上升单边（多头排列 MA5 > MA10 > MA20）：**
- ⚠️ **整体不建议做T**，很容易踏空
- 如坚持：每次T量不超持仓 20%，买回位设在 MA5，绝不等黄线
- 止损：日内低点跌破即认亏

**下降单边（空头排列 MA5 < MA10 < MA20）：**
- 可做"反弹T"：等价格反弹至黄线上方 +0.5% 以上卖出
- 买回等缩量再创低，不追杀跌（量不缩不买）
- ⚠️ 下降趋势中做T是高风险操作，须严格控制T量

---

## 核心指标解读

### 黄线（分时均价线）

分时图里那条黄色的线，是**今日所有成交的加权平均价格**。

```
黄线 = 今日累计成交额 ÷ 今日累计成交量
```

**为什么黄线重要？**
- 高于黄线 → 当前价格高于当日平均成本，平均持仓处于浮盈状态
- 低于黄线 → 当前价格低于当日平均成本，平均持仓处于浮亏状态
- 黄线本身是日内重要的成本参考与支撑/压力候选，仍需价格结构确认

| 偏离度 | 含义 | 做T意义 |
|--------|------|---------|
| > +2% | 价格明显高于今日平均成本 | T的卖出窗口 |
| +0.5%~+2% | 轻微偏贵 | 可挂单等待更高位 |
| -0.5%~+0.5% | 均值附近 | T的空间很小，不划算 |
| -0.5%~-2% | 轻微偏便宜 | 接近买回窗口 |
| < -2% | 价格明显低于今日平均成本 | T的买回机会，注意量能 |

---

### 量能节奏

盘中量能节奏使用**已完成的近5分钟 vs 已完成的前5分钟**；当前尚未完成的一分钟只显示实时价格，不进入量比。

| 当前量 vs 均量 | 含义 |
|--------------|------|
| 当前分钟量 > 均量 150% | 放量，有主动买/卖力量介入 |
| 当前分钟量 80%~150% | 正常量 |
| 当前分钟量 < 80% | 缩量，主动交易减少 |

**关键组合：**
- 🔴 价涨 + 缩量 → 卖出区内常提示上涨乏力，仍等走弱结构确认
- 🔴 价格偏离黄线 +1.5%+ + 缩量 → 进入卖出观察区，需结合黄线方向与价格行为
- 🟢 价跌 + 缩量 → 买回区内可观察下跌钝化，仍等止跌/转强结构确认
- 🟢 价格偏离黄线 -1%+ + 缩量 → 进入买回观察区；黄线下行时不逆势接回
- ⚠️ 价涨 + 放量 → 趋势性上攻可能增加，不因进入卖出区机械T出

---

### BOLL 布林带（日线）

由 20 日均线（中轨）± 2倍标准差 构成的"价格通道"。

```
上轨 = MA20 + 2σ（偏贵区间上限）
中轨 = MA20（价值中枢）
下轨 = MA20 - 2σ（偏便宜区间下限）
带宽 = (上轨 - 下轨) / 中轨 × 100%
```

| 带宽 | 市场状态 | 做T适合度 |
|------|---------|----------|
| < 5% | 极度收窄，即将变盘 | ⭐⭐ 谨慎，空间小 |
| 5%~10% | 正常震荡 | ⭐⭐⭐⭐ 最适合做T |
| 10%~15% | 趋势扩张 | ⭐⭐ 需配合趋势方向 |
| > 15% | 强趋势，大幅波动 | ⭐ 高风险，不建议 |

---

### 均线排列（日线判断形态）

| 排列 | 判断 | 做T策略 |
|------|------|---------|
| MA5 > MA10 > MA20 | 多头排列（上升单边）| 不建议做T，跟涨优先 |
| MA5 < MA10 < MA20 | 空头排列（下降单边）| 谨慎做T，反弹T |
| 三线粘合（差 < 2%）| 震荡整理 | 积极做T，高卖低买 |
| MA5 上穿 MA10/MA20 | 金叉，趋势转涨 | 减少做T量 |
| MA5 下穿 MA10/MA20 | 死叉，趋势转跌 | 减少做T量 |

## T位计算方法

### 基准价：分阶段选择

```
开盘确认阶段（6~30根）：基准 = 今开（黄线不可靠）
盘中阶段（≥31根）：      基准 = 分时均价（黄线）
```

### 开盘阶段 T 位（场景阈值 × 日线形态微调）

路径：**场景定区间 → 日线形态抖动调整**

| 场景 | 卖出区（基准=今开） | 买回区（基准=今开） |
|------|---------------------|---------------------|
| 🔻 高开回落 | +0.3% ~ +1.2%（反抽即出） | -0.8% ~ -2.0%（回落接） |
| 🚀 高开续涨 | +2.0% ~ +4.0%（等明显冲高） | -0.3% ~ -1.0%（浅回踩接） |
| 🟢 低开企稳 | +0.5% ~ +1.5%（反弹至今开附近） | -0.3% ~ -1.2%（回踩接） |
| 🔴 低开续跌 | +0.0% ~ +0.8%（反抽稳就出） | -2.0% ~ -4.0%（等量极缩） |

日线形态微调：
- **下降单边**：卖出更积极（-0.2~0.3%），买回更保守（+0.3~0.5%）
- **上升单边**：卖出更保守（+0.3~0.5%），买回更积极（-0.2~0.3%）

### 盘中阶段 T 位（黄线偏离 × 黄线方向）

盘中从第 **31 根有效分钟K** 起，以黄线为基准。基础阈值会先按近 10 个交易日平均振幅缩放：

```text
volScale = clamp(近10日平均振幅 / 2.5%, 0.35, 1.00)
```

这只会收窄低波动标的的区间，不会放大高波动标的；卖出上限还会受日线 BOLL 上轨限制，买回下限不会低于日内低点。

| 黄线方向 | 判定（近15分钟黄线累计变化） | 卖出区相对黄线 | 买回区相对黄线 | 代码语义 |
|---|---|---|---|---|
| ↘️ 下行 | ≤ -0.12% | +0.35% ~ +1.05% × volScale | -0.90% ~ -2.00% × volScale | 卖出区贴近动态压力；买回区仅作止跌观察，不自动接回 |
| ➡️ 走平 | -0.12% ~ +0.12% | 震荡：+1.50% ~ +2.80% × volScale；趋势：+0.80% ~ +1.50% × volScale | 震荡：-0.80% ~ -1.80% × volScale；趋势：-0.30% ~ -1.00% × volScale | 标准双向做T，仍需位置内的价格行为确认 |
| ↗️ 上行 | ≥ +0.12% | +1.45% ~ +2.65% × volScale | -0.15% ~ -0.65% × volScale | 卖出区上移为兑现区；买回位靠近黄线，避免深等或低位追卖 |

> 表内百分比是**计算阈值**。代码会按标的价格精度（例如 A 股两位小数）将最终买卖价取整，因此反推图上显示价格的实际百分比时，可能出现约 `0.01%~0.05%` 的尾差。

> 卖出上限仅在 BOLL 上轨高于卖出区起点时受其约束；若基准价已经越过 BOLL 上轨，不会用上轨反向压低卖出区上界。系统保证卖出区和买回区的上下界顺序有效。

其中“趋势”仅指日线形态为 `uptrend` 或 `downtrend`；`swing` 与 `unclear` 均使用震荡阈值。黄线方向一旦明确，会优先采用对应行的盘中阈值。它只改变区间与操作过滤，**不能取代位置和价格行为确认**。

### 手续费（双边成本估算）

**个股（万0.8，无免五）：**
```
买入手续费：万0.8（无最低门槛，按实际计）
卖出手续费：万0.8
印花税（卖出）：千1（单向）
过户费（沪市）：万0.2 × 双向 = 万0.4

双边总成本 ≈ 0.30%（万0.8×2 + 千1 + 万0.4）
```

**ETF（万0.1，免五，无印花税，无过户费）：**
```
买入手续费：万0.1（免五，最低5元但ETF够量通常不触发）
卖出手续费：万0.1
印花税：无（ETF 免印花税）
过户费：无（ETF 免过户费）

双边总成本 ≈ 0.02%（万0.1×2）
```

> 做T差价需覆盖手续费才有意义：个股振幅 < 0.45% 不建议操作；ETF 振幅 < 0.08% 不建议操作。

> 以上为默认估算值，可在 `config.json` 的 `tFees` 中覆盖佣金、最低佣金、印花税、过户费和基金双边费率；报告中的净收益统一注明“按默认费率估算”。

## 常见问题

**Q：为什么机器人判断是"震荡"，但我感觉明显在涨？**  
A：机器人基于日线近20日数据判断，"震荡"是指中期结构无趋势。短期1-2日的涨跌不代表中期方向，日线均线排列是更稳定的参考。

**Q：T的数量应该多少？**  
A：通常建议 10%~30% 的仓位。太少，降成本效果微弱；太多，一旦买不回来，被迫空仓踏空。

**Q：买回没买到怎么办？**  
A：卖出后当日收盘前未买回，明日变成空仓（减仓了）。这也是做T的主要风险——**卖出容易，买回要耐心**。不要因为没买到就追高，宁可等下一个机会。

**Q：下降趋势中做T有意义吗？**  
A：有，但风险高。每次T只能降一点点成本，但如果继续大跌，降的那点均价远不够。下降趋势中更重要的是判断是否该止损，而不是拼命做T。
